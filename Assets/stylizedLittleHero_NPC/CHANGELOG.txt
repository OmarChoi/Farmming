VERSION 1.1 - Character Customization System
---------------------------------------------
Release Date: January 2026

NEW FEATURES:
✓ CharacterPartSwapper script - Complete customization system
  - Swap Body, Hair, Hat, Eye, Mouth, Eyebrow, Cheek parts
  - Next/Previous methods for easy cycling
  - Direct index setting (SetBody, SetHair, etc.)
  - Random customization (RandomizeAll)

✓ Automatic bone rebinding system
  - No more "weight stuff" issues
  - Handles all bone matching automatically
  - Works with all body variations (NPC_body_M1, M2, F1, F2)

✓ CharacterCustomizeUI script - UI integration helper
  - Easy button connection system
  - Index display support
  - Auto-wiring of events

✓ Demo scene included
  - Shows all customization features
  - UI example with buttons
  - Multiple character variations

FIXES:
✓ Fixed mesh renderer switching issues
  - Resolved "Rendering stopped" error
  - Fixed vertex stride mismatch
  - Proper SkinnedMeshRenderer handling

✓ Fixed bone binding problems
  - Automatic bone name matching
  - Fallback search for missing bones
  - Root bone auto-detection (Bip001)

✓ Fixed Unity rendering bugs
  - Mesh cleared before reassignment
  - Bounds recalculated properly
  - Force matrix recalculation enabled

✓ Fixed pivot points for hair prefabs
  - All hair parts now align correctly with head_dummy
  - No position offset issues

✓ Fixed pivot points for facial feature prefabs
  - Eyes, mouth, eyebrow, cheek parts properly centered
  - Consistent positioning across all variations

IMPROVEMENTS:
✓ Better error handling and logging
